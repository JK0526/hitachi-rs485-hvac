- [ ] 斷線／Timeout／CRC／Exception 後無寫入自動重播，原有重連／Backoff 恢復；保持至少 75 ms turnaround。
- [ ] 每台裝置新增室內溫度 Sensor，預設啟用，°C／Temperature／Measurement；與 Climate 當前溫度一致且無新增讀取封包。

## 設計與驗證依據

手動 UI 操作與封包結構參考 Coselig Modbus Hub v1.6.5 的 monitor.py/js、protocol.py、transport.py；只重用操作方式與隔離原則，Hitachi 寫入驗證沿用本專案 profiles.command。

HA data_entry_flow.async_notify_flow_changed 發送 refresh 事件；官方前端 dialog-data-entry-flow 在該事件清空 progress。因此本版先通知描述 refresh，再送 async_update_progress，保留事件順序，沒有修改 Scanner 識別或能力探測。

- https://github.com/JK0526/coselig-modbus-hub/tree/v1.6.5
- https://github.com/home-assistant/frontend/blob/dev/src/dialogs/config-flow/dialog-data-entry-flow.ts

手動命令由 authenticated WebSocket 入口驗證，寫入確認欄位與所有封包結構均在後端驗證。Transport 使用 shield 保持取消後的交易隔離，讀取與寫入均不直接覆寫 confirmed cache。室內溫度沿用 Fast Poll cache。

本機自動化與 GitHub Actions 通過後才建立新 Tag；實機電氣／Gateway／快取更新行為仍須依上列清單確認。
