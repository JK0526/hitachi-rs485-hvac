## Known Limitations

1. 實際硬體相容性待上述驗收。初始提交的 feature PR 未合併前，HACS 的預設主線尚未包含實作；可由 feature branch 手動安裝，主線合併／正式 release 由 repository 擁有者決定。
2. RC-R02XT Air Conditioner 是唯一正式支援的 profile。RC-R01XT、除濕機、全熱交換器、8 房控制器、Swing、raw write 不在此版範圍。
3. 官方快取狀態每秒更新，第一次讀回可能仍是舊快取；正常輪詢會校正。Poll=0 時可用 HA `homeassistant.update_entity` 明確刷新。
4. 現場模式／風速組合限制可能回傳 DeviceException；不猜替代碼、不重試寫入。商用額外風速碼保留 raw unknown，RPI 不提供 AUTO／Quiet。
5. 官方溫度欄位為 unsigned；未假設負溫 two's-complement 編碼。Capacity 保留 raw，不推算未確認的完整型號。
6. Optional capabilities 在新增時探測；若當時 timeout，該 entity 不建立。確認硬體支援後重新搜尋並確認變更，即可為既有 Slave 增加能力；暫時性探測失敗保留既有能力，明確 exception 02 才移除。
7. 沒有 fake power，也沒有 energy／runtime reset UI。Energy 是硬體原始 counter；HA recorder 的長期統計與真實 Energy Dashboard 長時間顯示須現場觀察。
8. TCP host 驗證只證明網路連線，不能證明 RS485 或每台 Slave 已連通。Gateway 一般無加密／驗證，僅適合可信任網路。
9. 斷線或 framing ambiguity 後重開同一 Transport 的 stream，可能增加 cumulative connection counter；此計數不代表同時有兩個 scanner/sensor socket。
